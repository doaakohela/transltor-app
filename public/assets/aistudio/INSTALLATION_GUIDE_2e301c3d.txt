# How to Install LingoBoost in Google Chrome / Brave / Edge

Congratulations! You have downloaded the complete, 100% free Manifest V3 Chrome Extension.

## 30-Second Quick Installation:
1. Unzip this downloaded (.ZIP) file into a folder on your computer.
2. Open Google Chrome (or Brave, or Microsoft Edge).
3. In the address bar, type:
   chrome://extensions
   and press Enter.
4. In the top-right corner of the Extensions page, enable "Developer mode" toggle.
5. Click on the "Load unpacked" button in the top-left corner.
6. Select the unzipped folder.
7. Done! The LingoBoost icon will appear in your browser toolbar!
